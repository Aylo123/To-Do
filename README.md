# Миний өдөр

Ажил, сэтгэл санаа, календарь, өдрийн playlist-тэй хувийн төлөвлөгч.

## Бүтэц
Нэг `index.html` файл, гурван давхаргатай:
- **Data** — `LocalAdapter` (хөтчийн localStorage)
- **Logic** — `Planner` (дүрэм, ангилал)
- **UI** — `render*` функцүүд

## Анхаарах
Өгөгдөл тухайн хөтөч дээр хадгалагдана. Өөр төхөөрөмж эсвэл
өөр хөтчөөр нээхэд тусдаа хоосон төлөвлөгч харагдана.
